The crew

  2. Coder Implements the plan with its own tools.
  3. Reviewer Checks the work, then approves.

@Name hands the task across, with the conversation’s context.

Features

Per-agent memory

After every turn, the chat becomes a structured memory and comes back with that agent next session.

It is stored locally in SQLite at ~/.AgentCrew/memory.db, scoped to that agent.

Learn a rule

/learn proposes rules from the conversation: when this happens, do that. You confirm each one, or skip it.

Scope is global, for every chat, or project, for this one only.

Evolve the prompt

/evolve reads an agent’s memory and proposes a revised system prompt.

You accept, edit, or decline. Nothing changes until you do.

Craft a skill

Ask the agent to save a workflow you repeat. It writes instructions and at least one script.

The skill is saved in the project’s .agents/skills folder.
